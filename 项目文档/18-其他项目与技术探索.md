## 2. Rebuild the World —— 手机激光扫描 3D 场景重建

> 工作区：`D:\文档\Cursor\Rebuild the world` ｜ 1 会话 ｜ 2026-04-27

**想法来源**：一篇微信公众号文章，关于 **reality capture 技术** 和 **其域创新的 LCC 产品**。

**大胆的技术设想** ⭐：

> 「能不能用**苹果手机的激光扫描摄像头**替代 **SLAM 空间扫描硬件**，
> 结合 **3D 高斯生成技术**，通过手机生成扫描后的**场景重建**？」

**思路拆解**：

| 传统方案 | 设想方案 |
|---|---|
| 专用 SLAM 硬件 | **iPhone LiDAR 激光扫描** |
| 传统 3D 重建 | **3D 高斯泼溅（Gaussian Splatting）** |
| 高成本、重设备 | **普通手机即可** |

**价值**：把"专业级空间扫描"降到"人人可用的手机"，这是个很有想象力的方向。

# 全项目技术画像总结

## 技术栈分布

| 领域 | 高频技术 |
|---|---|
| **后端** | Python / FastAPI / Node.js / SQLAlchemy / PostgreSQL |
| **前端** | React 18 / TypeScript / Vite / Ant Design / Redux Toolkit / Canvas / Web Audio API |
| **AI 集成** | OpenAI / Claude（Opus 4.6）/ Gemini / DeepSeek / Kimi K2.5 / 腾讯混元 / SiliconFlow / Gemma 端侧 |
| **Agent 框架** | Claude Code / Codex CLI / nanoclaw / CLI-Anything / DOMShell MCP / 地图 MCP |
| **硬件** | Tuya T5AI-CORE / Link 2 云台摄像头 / iPhone 陀螺仪 / iPhone LiDAR |
| **语音** | openWakeWord / pvrecorder / TTS / STT |
| **部署** | GCP Cloud Run / Cloudflare Tunnel / Docker Compose / Ubuntu VM |
| **方法论** | Harness Engineering / 多 Sub Agent 并行 / Skill 工程化 / 渐进式披露 |

## 贯穿所有项目的设计理念

1. **Provider/Skill 化抽象** —— AI 模型、酒店数据源、Agent 能力都做成可插拔
2. **Harness Engineering** —— 机械门 + LLM Judge + Trace 三层保护
3. **多 Sub Agent 并行开发** —— 复杂改造时开多个 GPT-5.5/Claude subagent 分头推进
4. **先量化再优化** —— 客服 Agent、模型评测、EDM 都建立在数据基础上
5. **MVP 敢划边界** —— 明确"先不做"什么，才能跑得快
6. **自动化留人工卡点** —— 生成全自动，不可逆动作（发布）必须确认

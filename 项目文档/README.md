## 本项目最值得关注的三个技术亮点

1. **EDM 平台的 Harness Engineering 实践** —— 机械门 + LLM Judge + Trace 三层保护，让多 Agent 系统从"能跑"变成"可治理"
2. **客服 Agent 的渐进式披露改造** —— 知识库从全量加载（24K tokens）改为按需检索（< 5K），省 80% 成本且降低幻觉
3. **多 Sub Agent 并行开发范式** —— 在 Baby Camera、First Aid 等复杂项目中反复使用，是效率关键

# 音乐与音频工具集

> 涵盖三个工作区：`musician`（7 会话）、`Extend Song`（3 会话）、`D:\Cursor` 下的音频播放器（53 会话中的一部分）
> 时间跨度：2026-03-25 ~ 2026-03-26

---

## 一、项目做了什么

围绕 **AI 音乐生成与音频可视化**做的几个前端工具：

| 子项目 | 内容 |
|---|---|
| **Musician Console** | AI 音乐生成控制台（多模态输入） |
| **Extend Song** | 音频续写（Audio Extend Song）功能 |
| **音频镜像频谱可视化播放器** | 基于 Web Audio API 的可视化播放器 |

---

## 二、Musician Console（音乐生成控制台）

### 2.1 技术选型

| 项 | 内容 |
|---|---|
| 生成能力 | **Google Gemini 音乐生成 API**（`ai.google.dev/gemini-api/docs/music-generation`） |
| 输入模态 | **文本 + 图片参考图**（多模态） |
| 图片限制 | **最多 10 张**（超过需处理） |

### 2.2 设计要点 ⭐

用户明确要求：

> 「我现在要做一个**专业的**音乐生成的**控制台**，包括文本输入，还有图片的参考图输入，**支持多模态**，最多可以输入 10 张图片，超过这个…」

即：
- 定位是**专业控制台**，不是玩具
- **多模态输入**：文本描述 + 参考图引导风格
- **容量边界处理**：10 张上限，超出要有明确处理逻辑

## 四、音频镜像频谱可视化播放器 ⭐

这是 `D:\Cursor` 主工作区里一个技术含量较高的前端项目。

### 4.1 技术栈

| 项 | 内容 |
|---|---|
| **音频解码** | **Web Audio API** |
| **渲染** | **Canvas** |
| 框架 | React（组件化，如 `VisualizationTabs`） |

### 4.2 视觉效果设计 ⭐

用户提供的参考：

> 「结合你提供的**视频（波形随着播放滚动、可拖拽）**和**图片（上下对称的镜像柱状图）**，
> 我们需要构建一个基于 Web Audio API 和 Canvas 的播放器。」

**核心视觉效果**：

| 效果 | 说明 |
|---|---|
| **镜像柱状图** | **上下对称**的柱状频谱（以中线为轴镜像） |
| **波形滚动** | 波形随播放**横向滚动前进** |
| **可拖拽** | 用户可拖动定位 |
| **Tabs 切换** | 多种可视化模式（`VisualizationTabs` 组件） |

### 4.3 实现演进

```
第一版：垂直方向的镜像柱状图
    ↓
优化：横向展开 + 窗口滚动前进播放
```

即从"静态上下对称"升级为"**横向滚动的时间轴式可视化**"，更有"播放"的动感。

## 五、交付物

- Musician Console（多模态 AI 音乐生成控制台，文本 + 最多 10 张参考图）
- Audio Extend Song 功能（音频续写）
- 音频镜像频谱可视化播放器（Web Audio API + Canvas）

  - 横向展开 + 滚动前进
  - 可拖拽、多 Tab 切换

---

## 六、复盘

1. **音频可视化的关键是"时间感"** —— 从静态镜像图到横向滚动，本质是让视觉跟随音频时间轴流动。
2. **多模态输入要设容量边界** —— 10 张图的上限必须有明确处理逻辑，否则会不可控。
3. **Web Audio API + Canvas 是音频可视化黄金组合** —— 前者提供频谱数据，后者提供高性能绘制。
